# JavaScript Learning

A structured collection of JavaScript concepts, experiments, and practice code built while learning JavaScript.

This repository contains hands-on examples and experiments created to understand JavaScript concepts through practical implementation.

## Topics Covered

The repository covers JavaScript concepts ranging from fundamentals to asynchronous programming and browser APIs.

Some of the major areas include:

- JavaScript fundamentals
- Variables and data types
- Operators and type conversion
- Functions
- Arrays and objects
- Scope and hoisting
- Execution context and call stack
- Closures
- DOM manipulation
- Events and event delegation
- Callbacks
- Callback hell
- Promises
- Promise chaining
- Async/Await
- Browser APIs
- Local Storage
- Timers
- Fetch API
- Error handling
- Modern JavaScript (ES6+)
